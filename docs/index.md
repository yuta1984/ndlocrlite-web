## 概要

NDLOCR-Lite Web は、PaddleOCR PP-OCRv5 をブラウザネイティブで実行する Web OCR ツールです。React 19 + ONNX Runtime Web (WASM) で構成され、画像・PDF からテキストを抽出します。全処理はブラウザ内で完結し、外部サーバーへのデータ送信は一切ありません。Web Worker 並列パイプライン・IndexedDB キャッシュ・XY-Cut 読み順推定により、プライバシー完全保護と高速化を両立。日本語・中国語・韓国語・英語の4言語に対応しています。
